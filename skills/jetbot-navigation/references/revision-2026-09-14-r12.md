# Revision 12 — perception speed

Date:2026-09-14, America/Los_Angeles. Builds on revision11; no powered trial
was performed during this revision.

Target optical flow now operates on the target rectangle plus96pixels of padding
instead of building pyramids for the full image. Both images share a crop origin;
coordinates are restored before geometric fitting. Points leaving the region
are rejected. Original-template identity, ambiguity, inlier and timing guards
are unchanged.

The same37 recorded Advil frames, repeated three times, measured median target
tracking39.43ms before versus11.72ms after, and p9556.53ms versus16.16ms.
There were zero tracking losses and at most0.0051pixel box-coordinate difference.
This is tracker processing latency, not whole robot travel time. See
`reports/iteration-2026-09-14/tracker-speed.json`.

Floor tracking also crops grayscale, feature extraction and optical-flow pyramids
to a560×312 region, preserving the original accepted floor-feature region and
restoring global pixel coordinates before geometry. Across111 recorded pairs,
median floor processing fell62.22→44.97ms (27.7%). There were zero outcome
mismatches; maximum translation difference was0.0036cm and yaw difference0.0032°.
Five focused tests cover coordinate restoration, yaw, exposure, exclusions and
texture failure. `FloorTracker(..., crop_flow=False)` retains the full-frame
fallback. See `floor-speed.json`. Independent component medians are not an
end-to-end control-loop benchmark.

`local_nav/benchmark_mission_speed.py --output REPORT` separates simulated powered,
stopped, turn, and recovery time. `--perception-ms` varies modeled target compute
(default45ms). Simulation timings exclude real Python search/render wall time;
recorded-image timings use wall time. Keep these measurements distinct.

With45ms modeled perception, the baseline angled approach took7.475s with3.450s
zero output; aligned travel took8.625s including7.475s uninterrupted driving.
With25ms modeled perception, the same approaches took7.220s and8.550s, both
within standoff tolerance with zero audited clearance violations. Faster compute
does not imply a proportional increase in driving speed. The25ms model is a
scenario assumption, not a guaranteed worst-case tracking/reacquisition time.

An earlier waypoint transition increased target loss and was reverted. A direct
initial-alignment experiment caused repeated turn/settle cycles and was also
reverted. Neither policy is enabled. The late-turn recovery remains a useful
next bottleneck; retain recorded failures rather than treating them as successes.

Battery, motor lease, tilt, full-chassis clearance and uncertainty guards remain.
Only one agent accesses hardware; heavy benchmarks run while the robot is stopped.
