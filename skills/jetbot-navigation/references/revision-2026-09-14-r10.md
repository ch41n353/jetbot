# Revision 10 — join adjacent drives to remove intermediate stops

Date: 2026-09-14, America/Los_Angeles. Requested by the user after distinguishing
local motor pauses from remote VLM latency. Earlier revisions remain preserved.

## Opt-in execution mode

Supply both `measured_map_drive: true` and `coalesce_drives: true` in the
supervisor's `plan_navigation` request. The plan and preview retain these flags;
execute normally with `spatial: true`. No new service or terminal is required.

The executor joins adjacent drives of the same sign into one run, up to30cm.
It does not join across a turn, direction reversal or target boundary. Preview
uses the same grouping so the next solid route represents the complete joined
motion. The complete joined chassis/braking envelope must fit the inspected map.

Joined runs over15cm have a four-second powered limit. Shorter runs and the
default mode retain two seconds. This explicitly extends the experimental
distance/time bound; it does not increase motor duty. Camera/IMU checks,180ms
renewal deadline,200ms expiring leases, stall/tilt/uncertainty guards, full chassis
clearance, battery interlock, cancellation tokens and final settling remain.
There is no heartbeat that keeps motors alive independently of valid tracking.

The original12 search-primitive budget is counted even when several primitives
become one motor run. Mission limits remain60seconds/90cm. Targets still require
a verified stop. Pulse-and-settle turning is unchanged in this revision.

## Validation and limits

Simulation verifies a30cm forward request uses one powered run and one final
settle with no intermediate stop or lease expiry. Tests also cover camera loss
and cancellation after the former15cm boundary, the four-second timeout, stops
before reversing at a target, grouping boundaries, and preview consistency.

The paired comparison is reproducible with:

```bash
/usr/bin/python3 local_nav/evaluate_coalesced.py --output comparison.json
```

It covers forward30cm, reverse30cm,20cm out-and-back, and turning/driving,
with four combinations of speed, coast, carpet texture, pivot and heading drift.
Results are in `reports/iteration-2026-09-14/coalesced-drive-comparison.json`.
The32-run comparison completed: joined mode reached16/16 targets, default
mode15/16. Default reverse seed4 exhausted the travel budget; preserve that
failure rather than include it as a successful timing sample. Neither mode
had an audited expanded-body boundary violation. Joined mode maximum true
endpoint error was2.782cm. Median forward30cm time fell3.987→3.195seconds
(two runs→one);20cm out-and-back fell6.487→4.820seconds (four runs→two).
The full112-test suite passed, followed by all seven focused joined-drive tests
including the added preview test; the narrower corridor return test also passed.

The simulator supplies IMU attitudes directly and checks static geometry;
it does not validate real motor behavior or detect newly moved obstacles.

No powered hardware test has been performed for this mode. After the earlier
empty-battery report and reboot, charger status and the current scene must be
established before a fresh preview and bounded live trial. Healthy voltage alone
does not establish that the robot is unplugged. Keep this mode opt-in.
